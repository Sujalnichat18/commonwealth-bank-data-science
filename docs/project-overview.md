# Project overview

## Objective

Explore how data analysis and data-management techniques can support business questions while protecting customer privacy.

## Workflow

1. Review the business questions and understand the available data fields.
2. Aggregate supermarket transaction data to investigate purchasing patterns.
3. Consider privacy risks in customer-level mobile-app data and ways to generalise identifying attributes.
4. Explore social-media posts using topic, sentiment, engagement, customer-intent, content-format, and response-needed fields.
5. Propose a relational database structure for users, posts, replies, quote posts, and public mentions.
6. Summarise findings and identify possible next analytical steps.

## Scope and limitations

This was a guided educational simulation using sample data. Results are descriptive and should not be generalised to the bank's actual customer base or live social-media performance. The database schema is a proposed design; it is not evidence of a deployed production database or live API integration.
